## 👨‍💻 Sobre mim

Desenvolvedor Full Stack Sênior com **7 anos de experiência** em SaaS B2B, Fintech e sistemas corporativos, especializado em React, Next.js, Node.js, NestJS e TypeScript. Meu foco é modernizar e evoluir aplicações críticas sem interromper a operação, com qualidade, escalabilidade e entrega de valor.

Comecei na programação criando servidores de GTA RP, onde aprendi na prática sobre performance, lógica de negócio e resolução de problemas. Hoje trabalho com o ciclo completo: frontend, APIs, integrações, infraestrutura e arquitetura.

- 🐛 Redução de **cerca de 30%** nos bugs em produção com code review e testes automatizados com Jest
- 🧪 Redução de **cerca de 25%** nos incidentes em produção com testes unitários e E2E em ambiente financeiro
- 🔗 Redução de **cerca de 40%** nos erros de integração na migração de um sistema crítico em COBOL para React e C#/ASP.NET Core
